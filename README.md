A [make.fun](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61)
entry for **One Star for Monday**: one line, a one-star review of Monday
written as though Monday were a restaurant — 25 words or fewer.

## The entry

> One star. I ordered the weekend and got Monday instead — cold coffee,
> burnt toast, and the bill was my whole week.

## Run

```sh
python3 main.py   # writes the review to /output/entry.txt
```

Deterministic: the program writes the same fixed line on every run.
No network, no dependencies, Python 3 standard library only.
